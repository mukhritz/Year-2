## 🍂 Semester 1: Core Systems and Architecture

### 🧱 Data Structure and Algorithm
This course explores the methods of organizing, managing, and storing data efficiently alongside designing step by step procedures to solve computational problems. It teaches how to choose the right data storage model like stacks, queues, trees, and graphs depending on specific operational needs. Understanding these foundational principles allows developers to minimize execution time and resource utilization in complex applications.

* **Key Concepts:** Stacks, queues, linked lists, trees, graphs, sorting algorithms, and time complexity analysis.

> 📖 **My Reflection:** > Learning how to calculate time complexity made me realize that writing code that simply works is not enough. Transitioning from basic arrays to complex structures like binary search trees and graphs opened my eyes to how massive search engines process data instantly. It was a rigorous module that completely changed how I approach algorithmic problem solving.
> 
> 🎯 **What I Gained:** > The ability to analyze algorithm efficiency using Big O notation and select optimal data structures to solve data bottlenecks.
> 
> 💡 **Areas for Improvement:** > I need to dedicate more time to practicing dynamic programming and complex graph traversal algorithms to better prepare for technical data challenges.

### 🗄️ Database
This course covers the core concepts of designing, implementing, and maintaining relational database management systems within a work based learning environment. Students learn how to structure data using normalization rules to eliminate redundancy and maintain high data integrity across enterprise systems. This knowledge is essential for writing efficient structured query language statements to handle large scale transactions smoothly.

* **Key Concepts:** Entity relationship diagrams, normalization, structured query language, database security, and transaction management.

> 📖 **My Reflection:** > Working on real database models taught me how critical data architecture is to a business. Translating complex business rules into structured tables and writing advanced multi table joins showed me how backend storage powers modern applications. It bridged the gap between raw data and organized corporate knowledge.
> 
> 🎯 **What I Gained:** > Mastery in database normalization up to third normal form and proficiency in writing optimized backend database queries.
> 
> 💡 **Areas for Improvement:** > I want to expand my knowledge into non relational databases like NoSQL systems because they are heavily utilized in modern big data engineering pipelines.

### 🌐 Network Communication
This course investigates how data is transmitted across local and global networks through various protocol layers. It covers essential topics like routing algorithms, IP addressing schemes, network security essentials, and the foundational OSI model. This understanding is crucial for configuring stable, secure infrastructures that transport massive data loads without loss.

* **Key Concepts:** OSI model layers, TCP IP protocol suite, IP subnetting, routing protocols, and basic network security.

> 📖 **My Reflection:** > Understanding how packets travel across the globe in milliseconds made me appreciate the hidden infrastructure of the internet. Calculating IP subnets and simulating network topologies showed me how crucial stable routing is to data availability. It is a vital subject for any data professional handling distributed systems.
> 
> 🎯 **What I Gained:** > Deep comprehension of network layers, the ability to configure network topologies, and practical skills in IP addressing architecture.
> 
> 💡 **Areas for Improvement:** > I want to dive deeper into cloud networking concepts to understand how virtual private networks operate inside modern cloud environments.
